I am a senior software engineer based in Monterrey, Mexico, with ten years of experience building C and C++ systems. My work spans embedded firmware, device platforms, API backends, and full-stack products, and I have led engineering teams in both technical and managerial roles. This post summarizes that experience; the complete record is on my [CV](/cv).

## Embedded systems at John Deere (2016 – 2022)

I began my career at John Deere as an embedded software intern and grew into a senior engineer and, later, a software supervisor. During those years I:

- Developed embedded applications for 16-bit microcontrollers in C and their graphical interfaces in Qt C++, processing vehicle data over CAN (J1939).
- Led the Mexico team responsible for the tractor display software, from microcontroller buffer logic to data interpretation and on-screen visualization.
- Founded and led a team that built simulators for the microcontroller, the CAN bus, and virtual product interactions, and led the design of a virtual Ethernet simulation for 32-bit FreeRTOS microcontrollers.
- Served as Scrum Master, reporting to stakeholders every sprint and presenting the plan for each program increment.
- As software supervisor, guided the professional development of more than ten engineers across five clients and designed the hiring and onboarding process for a growing team.

## Technical leadership at 3Pillar Global (2022 – 2023)

As a software tech lead, I resolved defects and delivered new functionality in C++ and WinCC OA, designed the DevOps infrastructure that supported a new licensing model and a migration to a modern technology stack, and built a Python proof of concept that helped secure a successful bid.

## Device platforms at GlobalLogic (2023 – 2025)

At GlobalLogic I worked on Amazon's next-generation Fire TV, porting a major third-party video streaming application to new devices. My focus was the middleware layer: adapting Google's Cobalt application runtime to the new hardware and to Amazon's new operating system, which is not based on Android. In parallel, I refactored and extended a Python test environment that automates embedded-system release processes, applying SOLID principles to make it maintainable for the long term.

## API backends at Svitla Systems (2026 – present)

I currently design C++ features for an API backend abstraction layer that allows a legal reporting system to migrate to a new platform version without disrupting existing clients, and I integrate AI-assisted capabilities where they add measurable value.
